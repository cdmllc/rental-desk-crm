# Rental Desk

不動産賃貸仲介の社内業務をまとめて管理するCRMです。顧客、案件、必要書類、タスク、売上、入金予定を1つの画面で確認できます。

## 主な機能

- ダッシュボードで進行案件、売上、入金予定、未入金、要対応案件を確認
- 顧客情報と担当者を手動登録
- 賃貸仲介の進行状況に合わせた案件ステータス管理
- 物件、内見、申込、契約、入居日程の管理
- 必要書類チェックリスト、タスク、メモの管理
- 仲介手数料、AD、その他報酬から総売上を自動計算
- 提携先支払額と自社入金予定額を料率に応じて自動計算
- 入金予定日、実入金日、入金済み・未入金の管理
- 管理者・担当者のメールアドレス／パスワード認証
- ログイン画面からの利用申請と、管理者による承認・却下
- 顧客・案件・タスクを担当者IDで分離し、API側でも担当外アクセスを拒否
- 管理者による担当者アカウントの追加、停止、権限変更、初期パスワード再発行
- 通信現場スタッフの稼働ダッシュボードと日報承認・差戻し
- スタッフ、所属会社、雇用区分、通信案件、現場、稼働区分、成績項目の管理
- 適用期間付き日給と、承認済み日報に基づく月次報酬計算・確定スナップショット
- 月次報酬CSV出力、案件別の売上・粗利管理
- CRM権限と稼働・報酬権限の独立管理
- `/staff` のスマホ専用画面から、本人の日報作成・提出・差戻し修正・報酬確認
- 利用申請時にCRM担当者／現場スタッフを選択し、承認時に権限を自動設定

## 技術構成

- React / Next.js互換構成（Vinext）
- TypeScript
- Cloudflare Workers / D1
- Drizzle ORM

## ローカル起動

Node.js 22.13以降とpnpmを使用します。

```bash
pnpm install
pnpm dev
```

既定では `http://localhost:5173` で起動します。

## ビルド

```bash
pnpm build
```

## データについて

初回起動時は操作確認用の架空サンプルデータを表示します。保存したデータはD1に保持され、ローカル環境ではブラウザ保存へフォールバックします。

## アクセス

ソースコードは公開しています。稼働中のCRMはアプリ内認証を有効にし、担当者は自分に割り当てられた顧客・案件・タスクだけを取得・更新できます。新しい担当者はログイン画面で自分のパスワードを設定して利用申請し、管理者の承認後にログインできます。管理者が直接発行した初期パスワードは、初回ログイン時に変更が必要です。

「稼働・報酬」は管理者専用モジュールです。CRMデータとは別のD1保存領域を使用し、`CRM権限` と `稼働・報酬権限` をアカウントごとに独立設定できます。現場スタッフは同じアカウントで `/staff` に入り、自分の日報と報酬情報だけを取得・更新できます。
